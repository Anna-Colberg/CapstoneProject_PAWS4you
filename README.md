# New Next Project

🐾 PAWS4you

PAWS4you is a web application designed for dog lovers.
It combines a comprehensive dog breed lexicon with a personal pet management system, allowing users to keep track of their own dogs and their individual needs.

✨ Features

📚 Dog Breed Lexicon
Browse detailed information about different dog breeds, including characteristics and general care needs.
🐕 Personal Pet Profiles

Create and manage profiles for your own pets to keep track of:
Age
Individual needs
Important information for daily care

🎯 User-focused Design

Simple and intuitive UI for easy navigation and usability.

🛠 Tech Stack

Framework: Next.js
Library: React
Styling: Styled Components

Package Manager: npm

🚀 Getting Started

Prerequisites
Make sure you have Node.js and npm installed on your system.

Installation
Install the dependencies:

** npm install

Running the Development Server
Start the local development server with:

** npm run dev


The app will be available at:
👉 http://localhost:3000

### Local Development

To work locally, please install the dependencies using `npm i` first.

Run `npm run dev` to start a development server and open the displayed URL in a browser.

Use `npm run test` to run the tests.

### Scripts

You can use the following commands:

- `npm run dev` to start a development server
- `npm run build` to build the project
- `npm run start` to start a production server
- `npm run test` to run the tests
